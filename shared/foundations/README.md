# Foundations and Prerequisite Refreshers

Use these free resources to fill gaps **before** attempting an assessment whose prerequisites you don't yet meet. None of them is graded.

| Area | You should be able to… | Free resources |
|---|---|---|
| **Python** | Write functions, modules and classes; use lists, dicts and comprehensions; read tracebacks | [The Python Tutorial](https://docs.python.org/3/tutorial/) · [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) |
| **Git and GitHub** | Commit, branch, merge, open a pull request, write a `.gitignore` | [Pro Git book](https://git-scm.com/book/en/v2) · [GitHub Skills](https://skills.github.com/) |
| **Command line and environments** | Create virtual environments, install requirements, run scripts | [Python venv docs](https://docs.python.org/3/library/venv.html) · [The Missing Semester (MIT)](https://missing.csail.mit.edu/) |
| **pandas and NumPy** | Load, filter, group, join and reshape tabular data | [pandas getting started](https://pandas.pydata.org/docs/getting_started/index.html) · [NumPy absolute beginners](https://numpy.org/doc/stable/user/absolute_beginners.html) |
| **Testing** | Write and run `pytest` tests and fixtures | [pytest getting started](https://docs.pytest.org/en/stable/getting-started.html) |
| **Probability and statistics** | Distributions, expectation, sampling, confidence intervals, hypothesis tests | [OpenIntro Statistics (free textbook)](https://www.openintro.org/book/os/) · [Khan Academy Statistics and Probability](https://www.khanacademy.org/math/statistics-probability) |
| **Linear algebra** | Vectors, matrices, matrix products, eigenvectors | [MIT OCW 18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) · [3Blue1Brown: Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra) |
| **Calculus for ML** | Derivatives, the chain rule, gradients | [3Blue1Brown: Essence of Calculus](https://www.3blue1brown.com/topics/calculus) |
| **Machine learning basics** | Train/validation/test splits, overfitting, basic models | [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) · [scikit-learn getting started](https://scikit-learn.org/stable/getting_started.html) |
| **Deep learning basics** | Tensors, autograd, training loops | [PyTorch tutorials](https://pytorch.org/tutorials/) |
| **LLM application basics** | Tokens, prompting, model APIs | [Hugging Face LLM Course](https://huggingface.co/learn/llm-course) |
| **SQL** | SELECT, JOIN, GROUP BY, window functions | [SQLBolt](https://sqlbolt.com/) · [DuckDB documentation](https://duckdb.org/docs/) |
| **Data protection** | What counts as personal data; lawful basis; minimisation | [Nigeria Data Protection Commission](https://ndpc.gov.ng/) |

**Self-check.** Each assessment's `prerequisites.knowledge` list in `metadata.yaml` is concrete. If you can't do an item from memory in 10–15 minutes, refresh it first.
