**Confidential, assessment-specific material** (marking guides, reference solutions, hidden tests, defence scripts, calibration exemplars) lives in the private **assessor kit** repository, under `solutions/<ASSESSMENT-ID>/`. Ask the Assessment Committee for access.

## Quick start for a new assessor
1. Read the assessor handbook (about 30 minutes).
2. Get assessor kit access, then set up the tools: `pip install -r requirements-ci.txt`.
3. Complete calibration on two exemplars in your subtrack.
4. Shadow one defence.
5. Mark your first submission, with double marking.
