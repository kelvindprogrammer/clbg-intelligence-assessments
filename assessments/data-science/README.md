# Data Science

> **Turning raw data into trustworthy evidence, insight and decisions.**

Data scientists answer questions with data, and they're honest about what the data can and cannot support. This subtrack assesses the whole analytical chain:
- sourcing data responsibly;
- cleaning and validating it;
- exploring it without fooling yourself;
- reasoning statistically and causally;
- forecasting;
- building reproducible pipelines;
- communicating findings to people who make decisions.

**What sets Data Science apart from the other subtracks.** ML Engineering is about building and operating predictive *systems*. AI Engineering is about building *applications* on foundation models. Data Science is about **inference and decisions**: is this effect real, how big is it, how sure are we, and what should we do? See the [competency framework](../../docs/competency-framework.md) for the shared and specialist competencies.

## How to use this subtrack

1. **Pick a tier.** [Tier 1](tier-1/README.md) · [Tier 2](tier-2/README.md) · [Tier 3](tier-3/README.md). See [tier definitions](../../docs/tier-definitions.md).
2. **Pick a unit** from the map below. Units are independent, so there's no required order.
3. **Pick any assessment** in that unit and tier. Each is a complete, self-contained project.
4. **Register, build, submit, defend.** See the [member handbook](../../docs/member-handbook.md).

**New to data science?** Start with the [shared foundations](../../shared/foundations/README.md) and [DS-T1-001](tier-1/units/DS-01-python-and-data-wrangling/README.md), or with any Tier 1 assessment whose prerequisites you meet.

**Typical tools:** Python, Jupyter, pandas/Polars, NumPy, SciPy, statsmodels, DuckDB/SQL, Matplotlib/Seaborn/Plotly, pytest. All are free and run on a laptop.
